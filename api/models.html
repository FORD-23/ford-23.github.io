API: модели

GET /models — список моделей. POST /models/{id}/predict — предсказание.

curl -X POST https://api.orbita.example/v1/models/churn-v3/predict \
  -H "Authorization: Bearer TOKEN" \
  -d '{"features": [0.4, 12, 1]}'
{"prediction": 0.82, "model": "churn-v3"}
